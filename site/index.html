Управление по Bluetooth

Busy Light

Подключите светильник по Bluetooth и выберите цвета верхнего индикатора и пяти передних светодиодов.

Сначала включите ESP32-C6, затем нажмите «Подключить устройство».

Если рядом несколько плат с именем BusyLight-C6, на время подключения включите только нужную.

Концевик нажат: верхний индикатор выключен.

#FF0000
#FFFFFF

Без подключения можно смотреть предпросмотр. После подключения цвета передаются на ESP. Переключатель «Наушники сняты» меняет только предпросмотр; физический концевик работает сам.
